# 카카오맵 페이지 구현/수정

## 필수 체크리스트

1. 좌표(latitude, longitude)는 반드시 **number 타입**으로 처리 (문자열 금지)
2. 마커는 **맵 컨테이너가 DOM에 렌더링된 후** 초기화
3. 클러스터러 인스턴스는 컴포넌트 언마운트 시 **정리(cleanup)** 필수
4. 마커/클러스터러 업데이트 시 기존 인스턴스를 먼저 제거 후 재생성
5. 지도 옆 리스트 패널은 **지도 컨테이너 높이를 초과하지 않도록** 독립 스크롤 적용

## 구현 순서

1. 현재 맵 컴포넌트 코드와 부모 레이아웃을 먼저 읽는다
2. 변경 계획을 설명하고 확인받는다
3. 구현 후 `npm run build`로 타입 에러를 확인한다

## 자주 발생하는 실수

- `toFixed()` 호출 전 값이 number인지 확인 (string이면 `Number()`로 변환)
- 줌 레벨 변경 이벤트에서 마커 재생성 시 무한 루프 주의
- 클러스터러 `clear()` 호출 누락으로 마커 중복 표시
